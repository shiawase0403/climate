# Global Climate Explorer Tutorial

Welcome to the Global Climate Explorer! This tool allows you to investigate climate data from around the world using the Köppen-Geiger classification system.

## Features

### 1. Single Location Mode
- **Click anywhere** on the map to retrieve detailed climate data.
- View temperature and precipitation charts.
- See the climate classification code and description.
- **Manual Input**: Enter latitude and longitude coordinates directly.
- **Search**: Find cities by name.
- **Explore Cities**: Browse a curated list of cities by climate type.
- **Download Report**: Generate a PDF report for the selected location.

### 2. Comparison Mode
- Switch to **Compare Locations** mode using the top navigation bar.
- Select up to **5 locations** on the map.
- Compare their temperature and precipitation data side-by-side.
- Download a comparative PDF report.

### 3. Game Mode (Climate Treasure Hunt)
- Test your geography and climate knowledge!
- We provide the climate data (charts and tables) for a mystery city.
- Your task is to **guess the location** on the map.
- **Score points** based on how close your guess is to the actual city.
- **Challenge Mode**: Play a 5-round scored challenge. (Note: Tutorial is disabled during challenges).

## Climate Classification

This app uses the **Köppen-Geiger climate classification**, which divides climates into five main groups:
- **A (Tropical)**: Equatorial, Monsoon, Savanna
- **B (Arid)**: Desert, Steppe
- **C (Temperate)**: Mediterranean, Humid Subtropical, Oceanic
- **D (Continental)**: Humid Continental, Subarctic
- **E (Polar)**: Tundra, Ice Cap

## Data Sources
- Climate data provided by **Mapresso**.
- Map tiles by **AutoNavi (GaoDe)** and **OpenStreetMap**.
